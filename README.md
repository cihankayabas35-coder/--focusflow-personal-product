# FocusFlow — Personal Product

Cycle 1 individual Personal Product for the Software Engineering course.

## Live App
Add the deployed URL here after publishing.

## Features
- Add, complete and delete daily tasks
- Automatic progress statistics
- Personal focus note
- Local storage persistence
- Responsive design for mobile and desktop
- No external dependencies

## Tech Stack
HTML, CSS and vanilla JavaScript.

## Deployment
The project can be deployed directly with GitHub Pages or Netlify. The entry point is `index.html`.

## Process
The app was developed using an AI-assisted / vibe-coding workflow. Requirements were translated into a small working prototype, then the interface and interactions were tested and refined.
